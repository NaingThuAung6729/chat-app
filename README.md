# chat-app

A simple chat app starter with:
- **Server**: Node.js + Express + TypeScript
- **Client**: React + TypeScript + Tailwind CSS (Vite)

## Getting started

```bash
npm install
```

### Run the server

```bash
npm run dev:server
```

The API will be available at `http://localhost:4000/api/health`.

### Run the client

```bash
npm run dev:client
```

The web app will be available at `http://localhost:5173`.
